A vast whale bursts from a tiny puddle on a sunlit city street: one impossible image made to spark an AI judge's excitement. A small program delivers the image to the entry's output folder.

## Run it

With a recent Node.js version that supports TypeScript directly, run this from the repository root:

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The program creates `output/entry.png`, ready to view.
